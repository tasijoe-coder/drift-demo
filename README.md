# 紅線千年

Vite + React + TypeScript 的手機直式互動小說。公開入口依序提供 **第〇世・杯中月**（無選擇序章）、**第一世・孟姜女**（六結局）、**第二世・梁山伯與祝英台**（五結局）、**第三世・王月英與郭華**（六結局）與 **第四世・錢玉蓮與王十朋**（六結局）。

你是月老，見證金童玉女從七夕宴、殿前受罰到牽線下凡的緣起。三場共 117 個逐句閱讀單位，上方以五張臺灣皮影風格的原創靜態插圖輔助情境，不使用關節動畫、操偶桿或唱戲。

## 本次公開版本

- 首頁故事按鈕依序為第〇世、第一世、第二世、第三世、第四世。讀完第〇世開啟第一世，再依前世任一結局完成逐世開啟。重讀不會重新上鎖，既有完成進度與有效結局收藏可銜接。其餘世與卡牌入口繼續隱藏。
- 每句文字指定一張靜態圖；畫面依句子進度在宴前、碎盞、殿前、渡口、空橋命簿之間切換，不逐句模擬人物動作。
- 可手動下一句、上一句，或自動閱讀；切到其他分頁時暫停自動計時。
- 三場讀完停在「第〇世・完」，不自動進入第一世；結束後仍可回看全部文字。
- 進度自動保存於 `hx.theatre.lifetime-zero.v2`。舊的卡牌、第一折與輪迴紀錄保留，不覆寫或遷移。
- 第一世共45段、96條完整走法、6個結局。每輪16段、6次選擇，正文12,647–13,539字（含標點，不含選項與角色標籤），預估45–60分鐘，依閱讀速度而異。
- 第二世共49段、96條完整走法、5個結局。每輪16段、6次選擇，實際正文12,659–13,436字，預估45–60分鐘。五結局正文與全部條件文句已完成，非架構摘要。
- 第三世共41段、64條完整走法、6個結局。每輪16段、6次選擇，實際正文12,611–13,015字，預估45–60分鐘；包含如期赴約、失約後重建、雙方告別及一方拒絕的不同收束。
- 第四世共47段、96條完整走法、6個結局。每輪16段、6次選擇，實際正文12,730–13,234字，預估45–60分鐘；求證、安置與尋人三條主線均已寫完，包含確實白頭、辭任自立、修復同住、兩地通信、五年重會及尚未相認。
- 第一世以整段小說捲動閱讀，選項位於本段結尾，沒有選擇倒數。可回上一段、回上一個選擇、調大字體，保存段落與捲動位置。結局需按下讀完才記入收藏，未讀結局隱藏名稱。
- 第一至第四世上方全程固定使用既有 `ledger.webp` 作暫代圖，未新增演出圖片、動畫或配音；序章原有逐句換圖保持不變。
- 第一世存檔為 `hx.novel.qin.v1`，結局為 `hx.novel.qin.endings.v1`，捲動書籤為 `hx.novel.qin.bookmark.v1`；序章完成標記為 `hx.theatre.lifetime-zero.completed.v1`，與各舊存檔分開。
- 第二世使用對應的 `hx.novel.jin.*` 鍵。兩世各有 `completed.v1` 永久完成標記；到達結局頁尚不算完成，按讀完才記錄。新版本不改名、不覆寫第一世既有存檔與書籤。
- 第三世使用 `hx.novel.tang.*`，沿用同一個小說引擎與逐世進度服務。三世共12個位置／書籤／收藏／完成鍵，保持隔離，完成第二世任一結局後可讀。
- 第四世使用 `hx.novel.song.*`，四世共16個獨立鍵。第三世任一結局按「讀完」後開啟，停留在結局頁尚不算完成；有效舊收藏與永久標記可銜接，重讀不重新上鎖。
- 圖片是新生成的當代皮影風格插圖，不是館藏複製品或經藝師驗證的歷史復原。圖像原始生成提示及來源檔名見 `public/art/zero-spec.json`。

## 文字調整原則

- 先以醒酒湯、讓過裙角、記住小傷等日常建立人物關係，再進入離別。
- 玉女主動承認自己的心意，金童的保護既是優點，也可能替她作了決定。
- 明示仙籍戒律、月老求情及判詞，使殿前衝突有因果；不把破杯直接等同七世重罰。
- 用「先問名字」、空著的雙手與停住的筆留下記憶，收束於月老的關切，不在序章加入選擇。

故事依民間七世輪迴母題作原創改編，並非特定電視劇逐場重現，亦不作史實敘述。

第一世先以補屋、照護父親、吃飯與婚前坦白建立關係，再由喜夜徵役分往查冊、救援及家書。選擇改變機會、知情時間與具體援手，不以隱藏好感分數鎖死結局。所有路線不安排兩人另配他人；白頭人間確實相伴至白髮，死亡確認後的路線不復活。完整正文、各節去向與六結局說明見 [第一世全文與分支](docs/第一世全文與分支.txt)（含劇透）。

第二世先寫三年同窗、親口坦白或授權轉信、兩種十八相送及完整樓臺會，再分往退親、離家與病中等待。不同坦白方式不會混用知情狀態；合流仍保留求助方式、生活安排與告別前情。五結局均不另配他人，山伯死亡後不復活。全文見 [第二世全文與分支](docs/第二世全文與分支.txt)（含劇透）。原傳說化蝶仍留作架構對照，未新增獨立原命閱讀入口。

第三世以胭脂鋪的日常相識、落第後的坦白、元宵前的準備鋪陳，兩條主線分別寫如期相見與酒後失約。新編讓信物回到本人手裡，重建關係須經實際相處，亦尊重不再見面的決定；六個可玩結局中的兩人皆活著，不以死亡還魂或官府判配收束。完整正文、傳說參考與去向見 [第三世全文與分支](docs/第三世全文與分支.txt)（含劇透）。本世沿用原專案「唐」篇章排序，採架空民間城鎮，不混入宋代包公。

第四世取《荊釵記》母題，先寫訂情與婚後做活，再到中第拒婚、假休書與離散。分歧改變求證時機、藏身與尋人的代價，既有較早重會至白頭，也有五年江心相認；未圓線明示尚未確認彼此所在，不將傳聞當作死亡。兩人全線活著，不另配他人。避難、修書、通信與分歧生活為本版原創；不是歷史人物傳記，信物也不代替本人開口。全文與參考見 [第四世全文與分支](docs/第四世全文與分支.txt)（含劇透）。

## 驗證

```bash
npm ci
npm run lint
npm run build
npm run test:zero
npm run test:theatre
npm run test:novel
npm run test:jin
npm run test:tang
npm run test:song
npm run sim
```

`test:novel` 遍歷96條完整路徑，核對45段與6結局可達、每輪6次選擇、條件選項、正文長度、372個存檔檢查點、371次前後往返、完成門檻及舊存檔隔離。`test:zero` 檢查117句序章、圖片與跨場回讀。`test:theatre` 保留舊版分歧與存檔檢查。`sim` 驗證未改動的舊卡牌資料。

`test:jin` 遍歷第二世96條路徑，核對49段、五結局、372個還原檢查點、前後回讀、兩種坦白、E2各來源回收、死亡不復活、婚約善後、逐世永久解鎖及各世存檔／書籤／收藏隔離。

`test:tang` 遍歷第三世64條路徑、41段、六結局與256個還原檢查點，驗證每輪16段與六次決策、實際正文長度、共享結局的前情回收、12個獨立存檔鍵、逐世完成門檻與永久解鎖。

`test:song` 遍歷第四世96條路徑、47段、六結局與372個還原檢查點，核對所有條件補文可達、每輪16段／六次決策／實際正文長度、三個長線重會入口、全線存活、回讀清除未來狀態、第三世按讀完才解鎖及16個存檔鍵隔離。
