# 月老｜七世人間

開場採「極簡封面 → 800ms紅線連接 → 章節大廳」。封面滿屏不可捲動，使用APP Icon的皮影月老與Yuji Syuku標準字；大廳才顯示續讀、目錄、設定與音樂控制。從閱讀頁返回直接進大廳，舊進度保留。說明見docs/三段式開場.txt，驗證npm run test:opening。

背景音樂：五首使用者提供的MP3隨節點bgm欄位切換，同曲續播、2秒交叉淡化、最大增益0.45。右上音樂開關與原音效設定分開；首次互動解鎖，背景暫停、回前景淡入續播，靜音偏好永久保存。執行npm run test:bgm驗證；配樂標記與平台限制見docs/BGM實作說明.txt及docs/BGM節點對照.tsv。

Vite + React + TypeScript 的手機直式互動小說。公開入口依序提供 **第〇世・杯中月**（無選擇序章）、**第一世・孟姜女**（六結局）、**第二世・梁山伯與祝英台**（五結局）、**第三世・王月英與郭華**（六結局）、**第四世・錢玉蓮與王十朋**（六結局）、**第五世・秦雪梅與商琳**（六結局）、**第六世・賈玉珍與韋燕春**（六結局）與 **第七世・劉瑞蓮與李奎元**（六結局）。

你是月老，見證金童玉女從七夕宴、殿前受罰到牽線下凡的緣起。三場共 117 個逐句閱讀單位，上方以五張臺灣皮影風格的原創靜態插圖輔助情境，不使用關節動畫、操偶桿或唱戲。

## 文字調整原則

- 先以醒酒湯、讓過裙角、記住小傷等日常建立人物關係，再進入離別。
- 玉女主動承認自己的心意，金童的保護既是優點，也可能替她作了決定。
- 明示仙籍戒律、月老求情及判詞，使殿前衝突有因果；不把破杯直接等同七世重罰。
- 用「先問名字」、空著的雙手與停住的筆留下記憶，收束於月老的關切，不在序章加入選擇。

故事依民間七世輪迴母題作原創改編，並非特定電視劇逐場重現，亦不作史實敘述。

第一世先以補屋、照護父親、吃飯與婚前坦白建立關係，再由喜夜徵役分往查冊、救援及家書。選擇改變機會、知情時間與具體援手，不以隱藏好感分數鎖死結局。所有路線不安排兩人另配他人；白頭人間確實相伴至白髮，死亡確認後的路線不復活。完整正文、各節去向與六結局說明見 [第一世全文與分支](docs/第一世全文與分支.txt)（含劇透）。

第二世先寫三年同窗、親口坦白或授權轉信、兩種十八相送及完整樓臺會，再分往退親、離家與病中等待。不同坦白方式不會混用知情狀態；合流仍保留求助方式、生活安排與告別前情。五結局均不另配他人，山伯死亡後不復活。全文見 [第二世全文與分支](docs/第二世全文與分支.txt)（含劇透）。原傳說化蝶仍留作架構對照，未新增獨立原命閱讀入口。

第三世以胭脂鋪的日常相識、落第後的坦白、元宵前的準備鋪陳，兩條主線分別寫如期相見與酒後失約。新編讓信物回到本人手裡，重建關係須經實際相處，亦尊重不再見面的決定；六個可玩結局中的兩人皆活著，不以死亡還魂或官府判配收束。完整正文、傳說參考與去向見 [第三世全文與分支](docs/第三世全文與分支.txt)（含劇透）。本世沿用原專案「唐」篇章排序，採架空民間城鎮，不混入宋代包公。

第四世取《荊釵記》母題，先寫訂情與婚後做活，再到中第拒婚、假休書與離散。分歧改變求證時機、藏身與尋人的代價，既有較早重會至白頭，也有五年江心相認；未圓線明示尚未確認彼此所在，不將傳聞當作死亡。兩人全線活著，不另配他人。避難、修書、通信與分歧生活為本版原創；不是歷史人物傳記，信物也不代替本人開口。全文與參考見 [第四世全文與分支](docs/第四世全文與分支.txt)（含劇透）。

## 開發

閱讀介面保留深褐暗紅與暖金色，文學內容使用 Noto Serif TC／明體 fallback，系統功能使用黑體。全站右上統一設定面板，沿用音效與大字偏好；自動閱讀僅用於逐句演出，開設定即暫停。首頁突出可接續篇章，重讀第〇世降為次按鈕；正文頂部32px淡出、隱藏旁白標籤，選項加紅邊與底部留白。

潤稿目前移除29則副標中的機制／結局預告與抽象說理；第三世T2、T4及第六世L2、L4試作人物語氣與日常壓縮，各精簡約24–27%。其餘正文尚未全面潤稿。路由、狀態與結局數保留，詳見 [UI與潤稿試版說明](docs/UI與潤稿試版說明.txt)。

第八世〈霧港來電〉是1924年虛構港城的商業諜報番外，無政治或國家影射。全篇43節點、96條走法、6結局，每輪16段／6次決策，約35–50分鐘。三條長線為報館、護送離港與拍賣夜宴；兩位主角保留神仙記憶、每世各限三次仙息，月老可選擇有限幫忙。能力限制只在劇情中交代，不顯示仙息或介入數字，也沒有玩家主動施法的介面。全文、基準路線、角色與分支見 [第八世全文與分支](docs/第八世霧港來電全文與分支.txt)（含劇透）。

記下第七世任一結局後才顯示第八世入口，初始首頁完全隱藏；重讀前篇保留已開啟權限。上方沿用暫代圖。年代將依民初、八〇年代、千禧年、當代往後推進，目前僅民初篇已完成。

`test:fog` 遍歷96條路徑與331個還原檢查點，檢查每人至多三次仙息、至多兩次本篇月老介入、全條件正文、回溯資源還原，以及六種後日談完成門檻、永久開啟與獨立存檔。
