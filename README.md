# 紅線千年

Vite + React + TypeScript 的手機直式互動小說。公開入口依序提供 **第〇世・杯中月**（無選擇序章）與 **第一世・孟姜女**（六結局分歧小說）。

你是月老，見證金童玉女從七夕宴、殿前受罰到牽線下凡的緣起。三場共 117 個逐句閱讀單位，上方以五張臺灣皮影風格的原創靜態插圖輔助情境，不使用關節動畫、操偶桿或唱戲。

## 本次公開版本

- 首頁第一個故事按鈕是第〇世，第二個是第一世。讀完第〇世才開啟第一世，重讀序章不會重新上鎖；已有序章完成存檔亦可解鎖。其他世與卡牌入口繼續隱藏。
- 每句文字指定一張靜態圖；畫面依句子進度在宴前、碎盞、殿前、渡口、空橋命簿之間切換，不逐句模擬人物動作。
- 可手動下一句、上一句，或自動閱讀；切到其他分頁時暫停自動計時。
- 三場讀完停在「第〇世・完」，不自動進入第一世；結束後仍可回看全部文字。
- 進度自動保存於 `hx.theatre.lifetime-zero.v2`。舊的卡牌、第一折與輪迴紀錄保留，不覆寫或遷移。
- 第一世共45段、96條完整走法、6個結局。每輪16段、6次選擇，正文12,647–13,539字（含標點，不含選項與角色標籤），預估45–60分鐘，依閱讀速度而異。
- 第一世以整段小說捲動閱讀，選項位於本段結尾，沒有選擇倒數。可回上一段、回上一個選擇、調大字體，保存段落與捲動位置。結局需按下讀完才記入收藏，未讀結局隱藏名稱。
- 第一世上方全程固定使用既有 `ledger.webp` 作暫代圖，未新增演出圖片、動畫或配音；序章原有逐句換圖保持不變。
- 第一世存檔為 `hx.novel.qin.v1`，結局為 `hx.novel.qin.endings.v1`，捲動書籤為 `hx.novel.qin.bookmark.v1`；序章完成標記為 `hx.theatre.lifetime-zero.completed.v1`，與各舊存檔分開。
- 圖片是新生成的當代皮影風格插圖，不是館藏複製品或經藝師驗證的歷史復原。圖像原始生成提示及來源檔名見 `public/art/zero-spec.json`。

## 文字調整原則

- 先以醒酒湯、讓過裙角、記住小傷等日常建立人物關係，再進入離別。
- 玉女主動承認自己的心意，金童的保護既是優點，也可能替她作了決定。
- 明示仙籍戒律、月老求情及判詞，使殿前衝突有因果；不把破杯直接等同七世重罰。
- 用「先問名字」、空著的雙手與停住的筆留下記憶，收束於月老的關切，不在序章加入選擇。

故事依民間七世輪迴母題作原創改編，並非特定電視劇逐場重現，亦不作史實敘述。

第一世先以補屋、照護父親、吃飯與婚前坦白建立關係，再由喜夜徵役分往查冊、救援及家書。選擇改變機會、知情時間與具體援手，不以隱藏好感分數鎖死結局。所有路線不安排兩人另配他人；白頭人間確實相伴至白髮，死亡確認後的路線不復活。完整正文、各節去向與六結局說明見 [第一世全文與分支](docs/第一世全文與分支.txt)（含劇透）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `src/App.tsx` | 載入序章與第一世共用入口 |
| `src/hx/PrologueApp.tsx`、`prologue.css` | 首頁、解鎖與序章閱讀 |
| `src/hx/NovelReader.tsx`、`novel.css` | 第一世整段閱讀、選擇、回讀與結局 |
| `src/engine/novel.ts` | 純函式小說路由、條件文句與前情重建 |
| `src/data/lives/qin-novel.json` | 第一世45段正文、選項、條件與結局 |
| `src/hx/novel_save.ts` | 獨立小說存檔與永久序章完成標記 |
| `src/data/lives/lifetime-zero.json` | 第〇世三場文字、說話者、圖片 cue |
| `src/hx/zero_story.ts` | 第〇世存檔鍵、圖像表、前後句與閱讀進度 |
| `src/hx/theatre_story.ts` | 共用的純閱讀進度與存檔還原邏輯 |
| `public/art/zero/*.webp` | 五張 1200×800 靜態插圖，合計約 985 KB |
| `public/art/zero-spec.json` | image_gen 完整提示、參考造型與編碼設定 |

舊版第一折、卡牌引擎與各世 JSON 仍保留在原檔案。`src/hx/App.tsx`、`Theatre.tsx` 和 `CelestialPuppets.tsx` 不再由公開入口載入，後續需明確決定才重新開放。

## 驗證

```bash
npm ci
npm run lint
npm run build
npm run test:zero
npm run test:theatre
npm run test:novel
npm run sim
```

`test:novel` 遍歷96條完整路徑，核對45段與6結局可達、每輪6次選擇、條件選項、正文長度、372個存檔檢查點、371次前後往返、完成門檻及舊存檔隔離。`test:zero` 檢查117句序章、圖片與跨場回讀。`test:theatre` 保留舊版分歧與存檔檢查。`sim` 驗證未改動的舊卡牌資料。

## 開發

```bash
npm run dev
```

舊版《漂流者：信任臨界》保留在 `drifter-v2` 分支。

- [高雄市皮影戲館：影偶角色](https://kmsp.khm.org.tw/home02.aspx?ID=$4011&IDK=2&EXEC=D&DATA=11)、[影偶製作](https://kmsp.khm.org.tw/home02.aspx?ID=$4011&IDK=2&EXEC=D&DATA=22)：臺灣影偶的角色、材質、色彩與接合概念；本版轉為靜態視覺輔助。
- 孟姜女母題參考：[臺灣音樂館典藏《孟姜女》](https://openmuseum.tw/muse/digi_object/db82a7ba4cbaa6315c3da3720110cb62)與[孟姜女故事傳說](https://whly.hebei.gov.cn/c/2012-12-21/558051.html)。新小說的查冊、病中救援與各改命結局為原創發展；舊卡牌劇情與數值保留。
