# 紅線千年

手機直式的互動皮影戲與卡牌選擇遊戲（Vite + React + TypeScript）。

你是月老。玉帝罰金童玉女七世「配為夫妻，卻不許成婚」——孟姜女、梁山伯與祝英台……
每一世，把「天意」拖給四個人其中之一，改寫他們的命運。

首頁「走進第一折」進入皮影戲，會接續上次的進度；「從第〇世重新看」可從天上序幕重看。
第〇世依序演出七夕宴、殿前受罰與牽線下凡，沒有選擇；第一世則演出相遇、留宿與求親，三次分歧會接入不同後續台詞。
舞台人物是程式剪影暫代，尚未使用正式美術。

- 第一世・秦（孟姜女・范喜良）可玩，其餘各世製作中（完整版一次買斷解鎖）。
- 三個數值：紅線（太鬆緣盡、太緊殉情）、天規（插手太多被天庭發現）、劫數（悲劇逼近）。
- 前世記憶：試過的選擇會被記住，重玩時提示。結局卷收集所有結局。

## 結構
- `src/engine/fate.ts`：通用卡牌引擎
- `src/data/lives/*.json`：每一世的內容
- `src/hx/App.tsx`：畫面；`src/hx/sfx.ts`：程式合成音效
- `src/data/lives/qin-opening.json`：第〇世與第一折的演出、對話及分歧
- `src/hx/Theatre.tsx`、`theatre.css`：皮影舞台與對話；`theatre_story.ts`：閱讀進度與場次銜接
- `npm run test:theatre`：八條演出路線、存檔還原、第〇世無選擇與舊進度相容性
- `npm run sim`：平衡模擬

## 開發
```bash
npm install
npm run dev
npm run build
```

## 故事改編依據

參考傳統故事的輪迴結構、逃役入園相遇、婚後分離、託夢及送寒衣等母題，台詞、人物心理、張家求親與追捕文書等細節為本遊戲原創改編，不是特定電視劇逐場重現，也不作史實敘述。

- [國家文化記憶庫：《七世夫妻》](https://tcmb.culture.tw/zh-tw/detail?id=563187&indexCode=Culture_Object)：通俗小說版本與金童玉女七次輪迴框架。
- [國立傳統藝術中心臺灣音樂館典藏：《孟姜女》](https://openmuseum.tw/muse/digi_object/db82a7ba4cbaa6315c3da3720110cb62)：說唱版本的新婚別離、託夢與寒衣。
- [河北省文化和旅遊廳：孟姜女故事傳說](https://whly.hebei.gov.cn/c/2012-12-21/558051.html)：逃役入園、蓮池相遇及後世增衍情節。民間版本各有差異，本作不將其中一種視為唯一版本。
